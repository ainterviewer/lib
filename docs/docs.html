InterviewGuideContent

A guide for the interviewer to follow during the interview.

Field Type Description Required Default
framing Optional[str] A description of the interview and its purpose. Only used by the model. Yes -
introduction Optional[str] An introduction to the interview. Displayed to the interviewee as the first message. Yes -
question_sections ForwardRef('list[QuestionSection]') Yes []
outro Optional[str] An outro to the interview. Displayed to the interviewee as the last message. Yes -
alt_outro Optional[str] Used as if the a condition results in an EndInterview, eg. from missing consent. Yes -
timed_message ForwardRef('Optional[TimedMessage]') Yes -
evaluation_survey Optional[EvaluationSurvey] Yes -
shuffle_sections bool Should the sections be shuffled? Yes False

EvaluationSurvey

Information for evaluation survey hosted on surveyxact. If key is supplied, the interview id will be prefilled and sent to the variable named id.

key Optional[str] Yes -
id Optional[str] Yes -
